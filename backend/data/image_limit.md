## 上传图片规格

为保证图像处理算法运行稳定，系统对用户上传图片做如下限制：

| 项目 | 规格 |
|---|---|
| 支持格式 | jpg、jpeg、png、bmp、webp、tif、tiff |
| 不支持格式 | gif、mp4、avi、heic、raw、psd |
| 最小文件大小 | 10 KB |
| 最大文件大小 | 5 MB |
| 最小分辨率 | 128 × 128 |
| 最大分辨率 | 4096 × 4096 |
| 推荐分辨率 | 512 × 512 到 1920 × 1080 |
| 后端图像格式 | OpenCV BGR + uint8 |
| 不符合规格的处理方式 | 直接拒绝上传，不进入算法处理流程 |

### 上传校验规则

1. 文件格式不在允许列表中：拒绝上传。
2. 文件小于 10KB：拒绝上传。
3. 文件大于 5MB：拒绝上传。
4. 图片宽度小于 128px 或高度小于 128px：拒绝上传。
5. 图片宽度大于 4096px 或高度大于 4096px：拒绝上传。
6. OpenCV 或 Pillow 无法正常解码：拒绝上传。
7. 上传成功后，后端统一将图片转换为 OpenCV BGR 格式供算法处理。
