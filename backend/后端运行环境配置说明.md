# 后端运行环境配置说明

## 1. 环境要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 11 |
| Python 版本 | Python >= 3.11 |
| 虚拟环境 | venv |
| 依赖安装 | pip install -r requirements.txt |
| OpenCV 依赖 | opencv-contrib-python |
| 部署方式 | 本地运行 |
---

## 2. 创建并激活虚拟环境

在项目根目录执行：

```bat
python -m venv .venv
.venv\Scripts\activate
```

如果激活成功，命令行前会出现：
```
(.venv)
```
例如：
```
(.venv) PS D:\\Digital-image-processing-Design>
```
接着进行以下操作即可

## 4. 升级pip
```bat
python -m pip install --upgrade pip
```

## 5. 安装依赖
```bat
pip install -r requirements.txt 
```
如果下载很慢则使用清华源下载方案
```bat
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```
