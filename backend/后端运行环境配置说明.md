# 本文件用于说明 Windows 11 本地后端运行环境的配置方法。

## 1. 后端用途

本项目后端用于接收前端上传的动漫相关图片，调用 OpenCV、NumPy 等图像处理算法，返回处理后的结果图、步骤图、指标和中文分析说明。

后端使用 FastAPI，本地开发运行，不使用 Docker，不使用数据库，不引入大型深度学习模型。

## 2. 系统环境

推荐环境：

```text
Windows 11
Python 3.10 或 Python 3.11
venv 虚拟环境
```

## 3. 检查 Python

打开 PowerShell 或命令提示符：

```bat
python --version
```

如果没有版本号，请先安装 Python，并勾选 `Add Python to PATH`。

## 4. 创建虚拟环境

在项目根目录执行：

```bat
python -m venv .venv
```

## 5. 激活虚拟环境

在项目根目录执行：

```bat
.venv\Scripts\activate
```

激活后命令行前面通常会出现：

```text
(.venv)
```

如果 PowerShell 不允许执行脚本，可临时执行：

```bat
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.venv\Scripts\activate
```

## 6. 升级 pip

```bat
python -m pip install --upgrade pip
```

## 7. 安装依赖

如果当前在项目根目录：

```bat
pip install -r requirements.txt
```

如果当前已经进入 `backend/` 目录：

```bat
pip install -r ..\requirements.txt
```

依赖主要包括 FastAPI、OpenCV、Pillow、NumPy、SciPy、scikit-image 等课程项目需要的库。

## 8. 启动 FastAPI 后端

进入后端目录：

```bat
cd backend
```

启动服务：

```bat
uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

如果当前项目还没有 `main.py`，先完成后端接口文件后再启动 FastAPI。算法文件本身可以先用手动测试脚本验证。

## 9. 打开接口文档

后端启动后，在浏览器打开：

```text
http://127.0.0.1:8000/docs
```

这是 FastAPI 自动生成的接口文档页面。

## 10. 停止后端服务

在运行后端的命令行窗口按：

```text
Ctrl + C
```

## 11. 运行本地算法测试脚本

先准备测试图片：

```text
backend/data/test_images/anime_test.png
```

进入后端目录：

```bat
cd backend
python tests/manual_test_algorithm.py
```

使用示例配置：

```bat
python tests/manual_test_algorithm.py --config tests/sample_test_configs/grayscale_example.json
```

## 12. 查看输出图片

结果图片会保存到：

```text
backend/data/test_outputs/
```

步骤图会保存在类似目录：

```text
backend/data/test_outputs/result_steps/
```

## 13. 常见 Windows 命令问题

`python 不是内部或外部命令`：Python 没有加入 PATH，请重新安装 Python 或手动配置环境变量。

`无法加载 activate.ps1`：PowerShell 执行策略限制，使用：

```bat
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

`No module named app`：请确认运行算法测试脚本时位于 `backend/` 目录。

## 14. 常见依赖安装问题

如果安装 OpenCV 失败，先升级 pip：

```bat
python -m pip install --upgrade pip
```

如果网络较慢，可以更换镜像源，但不要修改项目依赖结构，不要引入 Docker 或数据库。

## 15. 常见图片路径问题

建议使用相对路径：

```text
data/test_images/anime_test.png
```

不要使用个人绝对路径：

```text
D:\个人目录\anime_test.png
```

这样其他组员拉取项目后也能直接运行。

## 16. 本项目不使用 Docker

课程项目按 Windows 11 本地开发方式运行，使用 `venv` 管理 Python 环境，不需要 Dockerfile、docker-compose 或容器部署。

## 17. 本项目不使用数据库

当前阶段图片处理和算法测试都使用本地文件，不需要 MySQL、PostgreSQL、MongoDB 等数据库。
