# 本文件用于说明后端算法文件统一框架的填写方法。

## 1. 算法文件是什么

算法文件是一个独立的 Python 文件，用于实现一个具体图像处理功能。每个文件都必须能够被后端动态导入，并通过统一入口 `run(image, params)` 执行。

## 2. 算法文件位置

所有算法文件都放在：

```text
backend/app/algorithms/
```

当前规范分类目录包括：

```text
grayscale_image/
color_image/
geometric_transform/
spatial_filter/
frequency_analysis/
frequency_filter/
```

不要新增旧版灰度、彩色或频域分析目录，统一使用当前规范分类目录。

## 3. 为什么一个算法一个文件

一个具体算法放在一个文件中，便于多人分工、单独测试、单独替换和后续注册到后端接口。不要把多个算法堆到一个大文件中。

## 4. 第一行中文说明

每个 `.py` 文件第一行必须写中文功能说明，例如：

```python
# 本文件用于实现图像 Canny 边缘检测算法。
```

这样组员打开文件时能立即知道文件用途。

## 5. ALGORITHM_META 写法

每个算法文件必须有：

```python
ALGORITHM_META = {
    "module": "grayscale_image",
    "name": "sobel_edge_detection",
    "display_name": "Sobel边缘检测",
    "description": "用于提取动漫图像中的人物轮廓、头发边缘和场景线条。",
    "params": {
        "threshold1": {"type": "int", "default": 80, "min": 0, "max": 255, "label": "低阈值"}
    }
}
```

`module` 是分类目录名，`name` 是文件名不带 `.py`，`display_name` 和 `description` 写中文，`params` 描述前端或测试脚本需要传入的参数。

## 6. run(image, params) 写法

每个算法文件必须有：

```python
def run(image: np.ndarray, params: dict | None = None) -> dict:
    """统一算法入口函数。"""
```

`image` 使用 OpenCV BGR 格式，类型是 `numpy.ndarray`。`params` 是参数字典，可以为空。

当前项目已经为每个算法文件提供可运行框架。组员后续正式开发时，优先只替换 `run(image, params)` 内部的处理逻辑，不要删除 `ALGORITHM_META`。

## 7. result 是什么

`result` 是最终处理结果图，必须是 `numpy.ndarray`，不能是文件路径、字符串或 `None`。

## 8. steps 是什么

`steps` 是算法过程图列表，用来保存中间步骤，格式如下：

```python
"steps": [
    {"name": "灰度图像", "image": gray},
    {"name": "边缘结果", "image": edge}
]
```

每一步必须有 `name` 和 `image`。

## 9. metrics 是什么

`metrics` 是指标字典，可以记录阈值、区域数量、平均灰度、边缘密度等数值。如果暂时没有指标，返回 `{}`。

## 10. analysis 是什么

`analysis` 是中文分析文本，用于说明算法处理效果。例如：

```python
"analysis": "Canny 算法可以突出动漫人物轮廓和场景线条。"
```

## 11. 统一返回结构

所有算法必须返回：

```python
return {
    "result": result,
    "steps": steps,
    "metrics": metrics,
    "analysis": analysis
}
```

不要直接 `return result`。

## 12. 如何替换占位逻辑

组员正式实现算法时：

```text
1. 保留文件第一行中文说明
2. 保留 ALGORITHM_META
3. 保留 run(image, params) 函数名和参数
4. 替换 run 内部的算法处理逻辑
5. 保证返回 result、steps、metrics、analysis
```

不要使用 `cv2.imshow()`，不要写个人电脑绝对路径。

## 13. 本地测试方法

进入后端目录：

```bat
cd backend
python tests/manual_test_algorithm.py
```

或使用示例配置：

```bat
python tests/manual_test_algorithm_advanced.py --config tests/sample_test_configs/canny_example.json
```

结果图会保存到：

```text
backend/data/test_outputs/
```

## 14. 成员提交检查清单

```text
□ 算法文件放在规范分类目录中
□ 文件第一行是中文功能说明
□ ALGORITHM_META 完整
□ run(image, params) 存在
□ result 是 numpy.ndarray
□ steps 是 list，且每项包含 name 和 image
□ metrics 是 dict
□ analysis 是中文字符串
□ 不使用 cv2.imshow()
□ 不硬编码个人绝对路径
□ 已运行 manual_test_algorithm.py
```
