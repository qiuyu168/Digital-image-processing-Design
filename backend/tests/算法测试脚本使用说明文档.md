# 后端算法本地测试配置示例

本文档用于配合 `manual_test_algorithm.py` 使用，帮助小组成员快速测试自己负责的算法文件。

当前测试脚本已经简化为：**使用者只需要修改 3 个路径即可运行测试**。

需要修改的 3 项是：

```python
INPUT_IMAGE_PATH = "data/test_images/anime_test.png"
OUTPUT_IMAGE_PATH = "data/test_outputs/result.png"
ALGORITHM_IMPORT_PATH = "app.algorithms.color_image.saturation_adjust"
```

其中：

| 配置项                  | 说明                         |
| ----------------------- | ---------------------------- |
| `INPUT_IMAGE_PATH`      | 要处理的本地图片路径         |
| `OUTPUT_IMAGE_PATH`     | 处理后的图片保存路径         |
| `ALGORITHM_IMPORT_PATH` | 要进行本地测试的算法导入路径 |

---

## 1. 使用前准备

请先准备一张测试图片，并放到：

```bat
backend\data\test_images\anime_test.png
```

然后在终端中进入 `backend` 目录：

```bat
cd backend
```

运行测试脚本：

```bat
python tests/manual_test_algorithm.py
```

运行成功后，结果图片会保存到：

```bat
backend\data\test_outputs\
```

如果算法返回了 `steps`，脚本会自动生成步骤图文件夹，例如：

```bat
backend\data\test_outputs\result_steps\
```

---

## 2. 注意事项

1. 本文档只提供路径配置示例。
2. 当前简化版脚本不需要手动修改 `PARAMS`。
3. 算法参数会自动从算法文件中的 `ALGORITHM_META["params"]` 读取默认值。
4. 每次测试只需要改 `INPUT_IMAGE_PATH`、`OUTPUT_IMAGE_PATH`、`ALGORITHM_IMPORT_PATH`。
5. 所有导入路径必须使用当前 6 类算法目录，不要再使用旧目录路径。

不要再使用旧路径：

```python
app.algorithms.gray_transform.grayscale
app.algorithms.color_processing.hsv_adjust
app.algorithms.edge_detection.canny
app.algorithms.frequency_filter.dft_spectrum
```

# 9. 最简操作流程

每个成员测试自己算法时，按下面步骤操作：

```text
第一步：把测试图片放到 backend/data/test_images/
第二步：打开 backend/tests/manual_test_algorithm.py
第三步：修改 INPUT_IMAGE_PATH
第四步：修改 OUTPUT_IMAGE_PATH
第五步：修改 ALGORITHM_IMPORT_PATH
第六步：在终端进入 backend 目录
第七步：运行 python tests/manual_test_algorithm.py
第八步：打开 backend/data/test_outputs/ 查看结果图
```

---

# 10. 提交前检查

每位成员提交算法前，请确认：

```text
□ 算法文件路径正确
□ 算法文件第一行是中文功能说明
□ 算法文件中有 ALGORITHM_META
□ 算法文件中有 run(image, params)
□ ALGORITHM_META 中 params 字段有默认值 default
□ 已经用 manual_test_algorithm.py 跑通过
□ data/test_outputs/ 中已经生成结果图
□ 如果算法返回 steps，步骤图也能保存
□ 控制台没有报错
```
